# VIBE254 🇰🇪

Connect • Chat • Vibe

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

The current frontend demo stores accounts and messages in browser localStorage. The live multi-user database/real-time server build can be added next.

## GitHub
Upload the extracted contents of this folder to your GitHub repository. Do not upload only the ZIP file if you want GitHub/Render to detect the Node project.
